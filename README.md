# Sales Analysis Using SQL

## Project Overview
This project analyzes sales data using SQL to derive business insights related to product performance, regional contribution, and sales trends over time.

## Dataset Overview
- Total records: 28
- Date range: January 2024
- Products: 5
- Categories: 2
- Regions: 4

##  Key Analysis Performed
- Total and average sales analysis
- Revenue contribution by product, category, and region
- Identification of top-performing products using Pareto (80–20) analysis
- Daily revenue trend and peak sales identification
- Sales behavior analysis using window functions (LAG)

##  Key Insights
- Total revenue generated: ₹803,300
- Electronics category dominates overall sales
- North region contributes over 30% of total revenue
- A small subset of products contributes to nearly 80% of revenue
- Sales show fluctuating trends over time rather than consistent growth

##  SQL Concepts Used
- Aggregation (SUM, AVG, COUNT)
- GROUP BY, HAVING
- Subqueries
- Window functions (LAG, running totals)
- CASE statements
